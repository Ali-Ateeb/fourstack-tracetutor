# Demo video

`demo.mp4` is an edited walkthrough made from actual browser screenshots, with synthetic Windows text-to-speech narration. It is not a continuous screen recording. Captures use synthetic examples. `narration.txt` and `captions.vtt` provide the transcript. Codex prepared these materials.

Published on YouTube as an unlisted video: https://youtu.be/i3-WKRW6HZ0 . Embedding is enabled and this URL is saved in the existing Devpost draft. This is a video publication, not a final hackathon submission. Caption import was saved in Studio; public caption availability is not yet verified.
